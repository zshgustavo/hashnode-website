Hoje é dia de explorar uma das novidades mais interessantes do ecossistema Google Cloud, anunciado durante o Google I/O desse ano (2026).

É o **Agent Studio**, o coração low-code e visual do **Gemini Enterprise Agent Platform**, a nova plataforma que substituiu o **Vertex AI**. O Agent Studio é um workspace colaborativo dentro do Google Cloud onde você consegue criar agentes de IA de forma extremamente intuitiva: você começa desenhando no canvas visual, testa em tempo real e, quando quiser, exporta tudo para código avançado.

Pense nele como um estúdio criativo onde *business users* e desenvolvedores trabalham juntos no mesmo espaço. Você começa desenhando tudo num canvas interativo lindo e intuitivo, sem escrever uma linha de código se não quiser.

Tem duas abas principais que mudam o jogo:

1.  Na aba **Flow** você monta o mapa completo do agente – *root agent, sub-agentes, instruções, modelos e ferramentas* – como se estivesse construindo um fluxograma vivo.
    
2.  Na aba **Preview** você testa tudo em tempo real, conversando com o agente exatamente como o usuário final faria, vendo na hora o que funciona e o que precisa ajustar. É tipo um protótipo interativo que evolui junto com a sua ideia.
    

Mas antes disso, vamos entender qual é a proposta de arquitetura dessa solução do Google com essa nova plataforma de agentes.

![](https://cdn.hashnode.com/uploads/covers/67507fa5ea99ce8d43cbccc8/a4f88f9b-235a-4745-ab87-2258c3076ebc.jpg align="center")

Como vocês podem ver nessa imagem oficial, o Agent Studio faz parte do Gemini Enterprise Agent Platform, com foco total em construir, escalar, governar e otimizar agentes de forma enterprise.

E por que o Agent Studio é tão incrível no dia a dia? Primeiro, pela forma como o refinamento de prompts funciona. Você só precisa dizer o que quer — *"deixe a instrução mais profissional e coloque uma etapa de verificação de dados"* — e a plataforma faz o ajuste fino, compara os modelos na hora e mostra a diferença na resposta. A interface é cheia de facilitadores: tem *minimap* para você não se perder naquelas instruções quilométricas e *slash commands* para agilizar os comandos.

O *grounding* também é coisa séria, focado no mundo corporativo: integração limpa com Google Search, Maps, Elasticsearch, Agent Search e RAG completo com os seus dados, tudo num ambiente seguro. Sem falar que a IA é multimodal nativa. Ela entende texto, imagem, vídeo, áudio e arquivos como se estivesse vendo o mundo através dos nossos olhos.

E o melhor: o caminho para quem está começando é absurdamente intuitivo. No Google Cloud Console, você abre o Agent Studio e já cria seu agente. Mapeia o fluxo no *canvas*, configura as regras da IA, escolhe se quer o peso do Gemini 3.1 Pro ou a velocidade do Flash, espeta as ferramentas e testa tudo na hora.

Ficou redondo? Você dá o *deploy* ali mesmo ou exporta a base em código puro para o Agent Development Kit com um clique.

![](https://cdn.hashnode.com/uploads/covers/67507fa5ea99ce8d43cbccc8/861ef08d-8a77-4978-a9b8-b82961832424.png align="center")

Logo nessa página — a inicial no Google Cloud, logo você já tem explicito o que é necessário para atuar nesse novo recurso do Google Cloud. Realizar a configuração do ADC e criar uma API Key, que serão necessários mais a frente.

![](https://cdn.hashnode.com/uploads/covers/67507fa5ea99ce8d43cbccc8/181445c7-2d40-445f-a06e-ae0929a20e1f.png align="center")

Com a facilidade, simplicidade e design interativo do Google Cloud não é difícil realizar todas as etapas que citamos acima — a integração do recurso com o ADK, o Google AI Studio é realmente muito chamativo para os quais nunca tiveram contato com criação de agentes ou plataformas na nuvem de desenvolvimento de aplicações de alto nível.

**A realidade bateu à porta de quem acreditava que criar inteligência artificial se resumia a enviar textos no chat.** Uma PoC às vezes nem tão funcional é muito diferente de um ambiente de produção resiliente. O Agent Studio acaba com essa ilusão ao trazer **governança, orquestração e ferramentas robustas de deploy.**

Como alguém que vive essa realidade técnica diariamente, eu garanto: o Agent Studio não é só mais uma ferramenta. **É o maior salto que o Google Cloud já deu para empresas que querem liderar a revolução dos agentes autônomos.**
